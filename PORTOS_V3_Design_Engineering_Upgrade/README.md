# PORTOS V3 — Precision Design & Spatial Digital Twin Upgrade

This is an **additive, implementation-ready instruction kit** for the **existing** PORTOS application. It extends the earlier 55-file original product kit and the V2 spatial upgrade; it does not replace working code or promise that the new models already exist.

## What changed from the previous direction
The earlier white/orange or sci-fi cockpit aesthetic is superseded. V3 adopts the supplied premium reference direction: **dark ocean/graphite, understated frosted glass, precise Urbanist typography, visual-first investigation, low-noise financial/operational charts, clear object hierarchies, and physically grounded Three.js ports/vessels.** The only high-energy color is used for meaningful selection or a true alert. More text is not a substitute for useful visualization.

## Contents
- `instructions/` — **64 individually scoped engineering + product-design specification files** across eight systems.
- `AGENTS.md` — integration and precedence contract; paste or merge into your existing project agent instructions.
- `CODEX_UPDATE_PROMPT.md` — instruction to execute the package phase-by-phase in your existing project.
- `PHASES_AND_GATES.md` — gated plan and acceptance evidence.
- `DESIGN_TOKENS.md` and `assets/design-tokens.json` — exact visual rules.
- `REFERENCE_MAPPING.md` and `references/` — user reference screenshots indexed by relevant design principle.
- `examples/` — typed JSON examples for new visual/3D integration concepts, **not** full production feeds.
- `manifest.json` — machine-readable list and sizes of all 64 files.

## Recommended usage
1. Copy this directory into the current PORTOS repo at `docs/portos-v3/`.
2. Point Codex to `docs/portos-v3/AGENTS.md` and `CODEX_UPDATE_PROMPT.md`.
3. Codex audits source and produces affected-file map; do not modify project until baseline tests/screenshot captured.
4. Implement gates separately. After every gate, compare real browser image with mapped user references and run regression tests.
5. Keep existing original skill attribution and review GPL-3.0 obligations for distributed product use.

## Important limits
No live AIS/berth/manifest data is supplied here. Existing synthetic fixtures must stay labeled **SIMULATED**. Ship/cargo animation is a representation, not certified maritime navigation or safety software. Visual reference image concepts are not code assets or guarantees of implementation.
