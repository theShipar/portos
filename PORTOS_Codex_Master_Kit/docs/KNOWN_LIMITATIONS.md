# Known Limitations Before Implementation

- No compiled frontend application or deployed URL is included in this instruction pack.
- The original map skill is China-oriented; global maritime geodata, port/ship 3D overlays and MapLibre port views require engineering work.
- Synthetic vessel/port/weather data cannot imply actual positions, safe routes, berth availability or forecasts.
- A real commercial implementation requires licensed AIS, weather and port events, data agreements, access control, backends, support and security reviews.
- GPL-3.0-or-later obligations of the original repository may affect proprietary reuse or distribution. Preserve credits and obtain legal review.
- Approximate port centroids and synthetic berth/anchorage geometry are unsuitable for vessel navigation.
