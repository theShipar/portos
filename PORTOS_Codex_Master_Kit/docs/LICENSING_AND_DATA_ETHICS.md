# Licensing, Provenance, and Responsible Demonstration

The original Three Scope Map GitHub repository by 宋夏天Dazzle is distributed under GPL-3.0-or-later with preservation requirements for attribution and notices. The skill must be reviewed before copying code into any proprietary commercial product. This kit does not redistribute the original 3D source or texture binaries.

Named port coordinates in prototype are *approximate reference centers*, not official port navigation or hydrographic coordinates. Vessels, voyages, positions, incidents, port waiting times, weather forecasts, costs and route options are synthetic. Any 2D basemap requires proper license and map attribution. Historical weather and AIS datasets added later may have separate licenses and privacy/data-use requirements.

Operator decisions are local demo-only and should never be interpreted as actual vessel instructions, real berth reservations, real communications or maritime safety advice. Production needs authenticated roles, audit logging, trusted licensed feeds, time-series ingestion, SLAs, fault tolerance, data lineage and safety review.
