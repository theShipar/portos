# Live Demonstration Runbook — Singapore Exception

This runbook is a repeatable portfolio demo using **synthetic data**, designed to validate product value and impressive map interactions.

1. **Global** — Reset demo, open `/operations` at `2026-11-09T12:00:00Z`. Show simulated fleet on Earth and compact KPIs. Explain that orange indicates entities needing review.
2. **Region** — Click Southeast Asia from an area cluster or search. Camera flies toward region; selected own fleet, routes and ports appear without card overload.
3. **Port** — Click Singapore port `PRT-SIN`. Enter 2D port detail and show anchorage/waiting zones; compare current queue with next 24h calls.
4. **Vessel** — Click `VSL-0001` MV Pacific Horizon. See vessel class, last synthetic position, planned Singapore -> Rotterdam voyage, scheduled/forecast ETA. Numbers remain consistent with global metrics.
5. **Incident** — Select `INC-0001` due to projected port-delay impact. Evidence should show +18h forecast ETA and rate $32,000/day = **$24,000 estimated exposure**. Do not imply certified demurrage.
6. **Decision** — Open comparison panel; examine `Monitor current plan`, `Request port-agent ETA confirmation`, and any documented candidate route scenario with constraints. Propose one action rather than 'reroute ship' automatically.
7. **Assign** — Assign local draft follow-up to a demo port call coordinator; update case to Investigating. Verify action visible in local audit log.
8. **Replay** — Enter voyage timeline; select event before/after ETA revision and observe position, event evidence, queue and forecast changes. Return to now.
9. **Back** — Navigate from incident -> vessel -> port -> region -> Earth, keeping logical selected/context state.
10. **Reset** — Use full demo reset; rerun same story and confirm deterministic starting numbers.

## Honest disclosure

Vessel positions, port wait states, weather events, berth status and all financial figures are illustrative scenario data. Map lines and port boundaries are not nautical charts and must not be used to navigate actual ships.
