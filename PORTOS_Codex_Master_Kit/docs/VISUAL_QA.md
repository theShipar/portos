# Visual QA Checklist

- [ ] Earth 1440×900 and 1920×1080: real WebGL, large central globe, sparse floating KPIs, no overdecorated HUD.
- [ ] Southeast Asia: regional map, ports, route density and stable camera.
- [ ] Singapore: 2D port map, visible synthetic anchorages, queue count reconciles.
- [ ] Vessel selected: inspector at 380–420px, readable ETA/speed, selected route focus.
- [ ] Incident selected: evidence and estimated exposure clearly labeled.
- [ ] Route comparison: planned vs proposed differences and sources.
- [ ] Replay: timeline and ship move from same simulated clock.
- [ ] 1024px, tablet: responsive panels and map remain usable.
- [ ] Reduced motion: no forced flythroughs or pulsing visual dependence.
- [ ] Browser developer console: no WebGL/resource/runtime errors.
